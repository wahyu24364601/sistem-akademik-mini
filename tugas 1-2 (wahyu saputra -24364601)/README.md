# Sistem Akademik Mini - Tugas Minggu 1-2

Nama: Wahyu Saputra  
Mata kuliah: Pemrograman Berorientasi Objek (PBO)

## Isi paket

- `class-diagram.mmd`: model domain utama sistem akademik.
- `usecase-diagram.puml`: aktor dan layanan utama.
- `sequence-pmb.mmd`: alur pendaftaran calon mahasiswa baru.
- `sequence-krs.mmd`: alur validasi dan pengajuan KRS.
- `ai-usage-log.md`: bukti penggunaan AI dan revisi manusia.
- `ADR-001-arsitektur.md`: alasan keputusan desain.

## Cara melihat diagram

1. Buka file `.mmd` di Mermaid Live Editor atau VS Code dengan ekstensi Mermaid.
2. Buka file `.puml` di PlantUML atau draw.io.
3. Periksa kembali identitas kampus, nama mata kuliah, dan aturan bisnis sebelum diekspor menjadi PDF.
